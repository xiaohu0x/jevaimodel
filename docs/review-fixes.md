# 修复与 SEO 交付记录

日期：2026-09-24。实施基线：`b682cad`（同步后的 `origin/main`）。首次审查使用了落后的 `939e432`；模拟引擎及旧版概率排序问题已被远端真实 Jev 接入取代。本轮保留真实 TypeSafe 调用、D1 用量控制、多语言首页和既有 SEO 页面。

## 已处理

- 草稿和最新结果按标签页保存，登录与站内导航后可恢复；Clear 同时清除保存的工作。浏览器禁止存储时给出提示，并允许用户明确选择继续登录但不保存。
- Clear、载入示例、离开页面、退出登录可取消浏览器中的分类请求；迟到响应不会覆盖新状态。服务端可能已消耗的请求额度仍以 D1 为准。
- 前后端共享问题数量、上下文长度、选项及评分等级校验。重复选项、不完整问题、损坏的 JSON、超长输入不会静默提交；缺失或格式错误的模型答案不会静默丢弃。
- 复制成功后才显示 Copied；退出失败保留登录状态并反馈；过期会话删除账号返回 401。OAuth 网络异常清理临时 Cookie，非法编码 Cookie 不再引发 500。
- 本地 OAuth 回调使用本地域名；账户状态支持重试、窗口重新聚焦刷新、UTC 日额度重置刷新。
- 登录、说明和删除确认使用带焦点管理、Esc 关闭和焦点恢复的弹窗。运行快捷键不会穿透弹窗。
- 清理未使用的组件、依赖和检查插件；博客正文拆成独立 JS 文件。CI 和部署前检查覆盖构建、Functions 类型、Lint、单元、SEO、DOM 交互。
- 修复服务端预渲染 hreflang 在客户端重复或残留的问题。Sitemap 和尾斜杠跳转从统一页面目录生成。
- 新增 `/blog` 和三篇英文文章，包含来源、内部链接、BlogPosting/BreadcrumbList、独立 canonical 和静态正文。已按用户批准开放索引。

## 验证

- `npm run verify`：完整构建、类型、Lint、64 个 Node 单元／SEO 测试和 7 个 DOM 交互测试。
- 本地 Cloudflare Pages + 独立临时 D1：主页及博客 200，尾斜杠 301，未知路由 404；过期会话删除 401；非法 Cookie 的账户读取 200；OAuth 本地回调和 no-referrer 正确。
- 浏览器：检查英文博客桌面正文、320px 导航/换行和横向滚动表格；修复了窄屏导航挤出问题。
- 模型接口验证使用公开官方合同和合成响应，不消耗生产模型额度；未用真实账号执行删除操作。
- 内容来源及语言审核见 `seo-research.md`。语言审核为模型审核；公开搜索遭反爬或返回无关结果，搜索意图仍需后续验证。用户明确允许先索引，再用 Search Console 验证选题。

本记录描述部署前的验证结果；实际发布状态以 Git 提交和 Cloudflare 部署记录为准。上线后再检查真实 URL 的收录状态和 Search Console 查询数据；本地通过不等同于已经获得搜索流量。
